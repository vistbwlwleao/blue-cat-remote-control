## Overview

Blue Cat Remote Control maps MIDI controllers or automation to any DAW parameter, enabling expressive real-time control of any plugin or mixer channel from hardware controllers.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Blue Cat Remote Control** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **MIDI Learn** | One-click MIDI learn assigns any CC or note to any parameter |
| **Macro Knobs** | Single knobs control multiple parameters simultaneously |
| **Automation** | Records MIDI performance as DAW automation for later editing |
| **Scaling** | Per-mapping range, curve, and inversion for precise control response |
